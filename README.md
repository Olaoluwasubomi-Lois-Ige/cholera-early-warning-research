# Machine Learning for Weekly Early Warning of Cholera Outbreaks in Nigeria and Benin

## Research Overview

This repository is being prepared to document computational research conducted as part of my MSc in Mathematical Sciences (Data Science) at the African Institute for Mathematical Sciences (AIMS Rwanda) in 2026.

The research examined machine learning approaches for weekly early warning of cholera outbreaks in Nigeria and Benin.

## Computational Research

The project involved:

- Processing infectious disease surveillance data for statistical analysis.
- Applying machine learning methods to weekly cholera outbreak prediction.
- Evaluating predictive model performance.
- Examining statistical results in the context of infectious disease early warning.

## Research Code

Selected Python scripts and Jupyter notebooks from the original research will be added after reviewing the code, its dependencies and data-sharing requirements.

The repository will document the computational methods, implementation details and validation procedures supported by the original research materials.
